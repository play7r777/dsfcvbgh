# Frontline Arena — PvP-арена на Roblox (Rojo + Luau)

Чисто PvP-режим: инфантерия с автоматом/пистолетом/C4/
минами, контейнерный лут (ПКМ, СВ-98), разбросанная по карте техника
(танк, мотоциклы) и FPV-дрон-камикадзе. Карта (1840×1840, с окопами)
и весь HUD генерируются кодом.

## Быстрый старт

```bash
rojo build -o "FrontlineArena.rbxlx"   # собрать плейс
rojo serve                             # живая синхронизация со Studio
```

## Управление

| Действие | Клавиша |
|---|---|
| Огонь (авто/полуавто) | ЛКМ |
| Прицеливание / оптика СВД | ПКМ (удерживать) |
| Перезарядка | R |
| Настройки прицела | `M` (ПК) / шестерёнка `⚙` слева снизу (touch) |
| C4: поставить (рейкаст ≤ 4 м) | ЛКМ с C4 в руках |
| Детонация C4 | ЛКМ с детонатором |
| ПТ-мина | ЛКМ с миной |
| FPV-дрон: запуск/выход | ЛКМ с планшетом, выход — Q |
| Дрон: курс и тангаж | **мышь** (вверх — дрон смотрит и летит вверх) |
| Дрон: газ/боковое скольжение | W/S + A/D (вертикаль — только мышью) |
| Танк: башня за мышью, выстрел | ЛКМ или F |
| Танк/мотоцикл: газ/руль | W/S + A/D (с сиденья) |

## Что нового в этой итерации

- **Фиксы крашей**: `ScopeFOV` у нестрелковых инструментов; `Vector2/Vector3`
  в вводе дрона (мышь дрона теперь работает).
- **Только первое лицо**: камера зафиксирована без возможности отдаления;
  системный курсор скрыт, поэтому на экране остаётся только игровой прицел.
- **PUBG-подобная отдача**: вертикальный recoil накапливается в очереди,
  горизонтальный увод следует оружейному паттерну с вариацией, camera kick
  сглаживается пружиной, а spread bloom восстанавливается после паузы.
- **Оружейные звуки**: для каждого оружия используется отдельный публичный
  Roblox-аудиоассет с небольшой вариацией громкости и высоты тона.
- **Камера дрона на носу**: впереди корпуса, ничего не загораживает; позиция
  сглаживается (телеметрия сервера 20 Гц).
- **Заполненная карта 1840×1840**: тактические высоты, воронки, земляные
  валы, сеть дорог, окопы, мосты, бункеры, руины, склады, артпозиции,
  наблюдательные вышки и равномерно распределённые полевые укрытия.
- **Оружие в правой руке**: серверный `WeaponVisualService` — процедурные
  low-poly модели, приваренные к кисти (R15/R6). Видны всем игрокам.
- **Компактный HUD**: вращающаяся шестерёнка настроек находится слева снизу,
  а справа снизу без панели и названия оружия отображаются только патроны
  `магазин/запас`. Настройки прицела сохраняются в DataStore.

## Стрельба: FastCast / Server-Validated Ballistics

Клиент мгновенно рисует трассер и звук; сервер валидирует (RPM, магазин,
перегрев, timestamp ±1 с, origin ≤ 8 studs от головы), восстанавливает разброс
по seed и прогоняет свою баллистику с гравитацией. Урон — через
DamageService / ArmorService.

## Броня танка (многокомпонентная модель)

| Узел | HP | Эффект при 0 |
|---|---|---|
| Корпус | 2000 | Уничтожение |
| Гусеница Л/П | 350 | Полная иммобилизация |
| Двигатель | 450 | Потеря хода + пожар 25 HP/с |
| Погон башни | 600 | <50%: поворот −60%; 0: заклинивание |
| Боеукладка | 300 | HEAT/AP: 35% шанс мгновенного подрыва |

Зоны: `Armor_Front` 0.5x, `Armor_Side` 1.0x, `Armor_Rear` 1.5x,
`Hitbox_Engine` 2.0x, `Hitbox_AmmoRack` 2.5x, `Hitbox_Track_L/R`.
Типы урона: Kinetic (угол + рикошеты), HEAT (игнорирует угол, бьёт узлы),
HE (сплеш, ×1.5 по гусеницам).

## 3D-ассеты (Blender headless)

`tools/blender/build_assets.py` генерирует FBX-модели всего оружия и пуль:

```bash
blender -b --factory-startup --python tools/blender/build_assets.py -- assets/fbx
```

Результат — `assets/fbx/*.fbx` (9 моделей: АК-12, МП-443, СВ-98, ПКМ, РПГ-7,
C4, детонатор, мина, планшет) и `assets/fbx/bullets/*.fbx` (9×19, 7.62×39,
7.62×54R, .338 Lapua, боевая часть РПГ). У стрелкового оружия зашита
анимация перезарядки `<Имя>_Reload` на костях `Root/Mag/Bolt` (магазин
извлекается/вставляется, затвор дёргается; длительность = ReloadTime из
конфига, 30 fps).

**Импорт в Roblox**: Asset Manager → Bulk Import → выбрать FBX. После загрузки
впишите asset id в `WeaponConfig.MeshIds` — `WeaponVisualService` подставит
MeshPart вместо процедурной модели. Анимацию перезарядки подключить через
AnimationController/Motor6D по костям `Mag`/`Bolt` (bone-parented парты;
при желании — перебить на skinned mesh в Blender).

## Структура

```
src/shared   — конфиги (баланс), Remotes, Ballistics, HitboxTags, Signal
src/server   — MapBuilder (карта x4, окопы), VehicleFactory, ArmorService,
               VehicleControl, WeaponService, ExplosivesService, DroneService,
               PickupService, LoadoutService, DamageService, SettingsService,
               WeaponVisualService
src/client   — WeaponController (отдача/прицел), DroneController,
               VehicleController, FXController, SettingsController, HUD
tools/blender— build_assets.py (генератор FBX)
assets/fbx   — готовые модели + пули
```
