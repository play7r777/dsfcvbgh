# Frontline Arena — PvP-арена на Roblox (Rojo + Luau)

Ветка `arena-core`. Чисто PvP-режим на небольшой карте: инфантерия с
автоматом/пистолетом/C4/минами, контейнерный лут (ПКМ, СВ-98), разбросанная
по карте техника (танк, мотоцикл) и FPV-дрон-камикадзе. Всё генерируется
кодом — ни одного бинарного ассета, карта/техника/HUD строятся на старте.

## Быстрый старт

```bash
# 1. Установить Rojo (см. aftman.toml):  rojo = "rojo-rbx/rojo@7.7.0"
# 2. Собрать плейс или работать вживую
rojo build -o "FrontlineArena.rbxlx"
# 3. В Roblox Studio: открыть FrontlineArena.rbxlx, затем:
rojo serve
# и нажать «Connect to Rojo» (плагін Rojo). Готово.
```

## Управление

| Действие | Клавиша |
|---|---|
| Огонь (авто/полуавто) | ЛКМ |
| Прицеливание / оптика СВД | ПКМ (удерживать) |
| Перезарядка | R |
| C4: поставить (рейкаст ≤ 4 м) | ЛКМ с C4 в руках |
| Детонация C4 | ЛКМ с детонатором |
| ПТ-мина (в землю перед собой) | ЛКМ с миной |
| FPV-дрон: запуск/выход | ЛКМ с планшетом, выход — Q |
| Дрон: полёт | WASD + Space/Shift |
| Танк: башня за мышью, выстрел | ЛКМ или F |
| Танк/мотоцикл: газ/руль | W/S + A/D (с сиденья) |

## Геймплей-цикл

1. Игрок спавнится с **автоматом, пистолетом, C4 + детонатором, ПТ-минами и
   планшетом FPV** (защита 3 сек).
2. **ПКМ и СВ-98** лежат в контейнерах снабжения по карте; после взятия
   контейнер пустеет и наполняется через 45–90 сек — лут бесконечный.
3. **Танк (2 шт.) и мотоциклы (3 шт.)** разбросаны по площадкам — их нужно
   найти и занять. Уничтоженную технику сервер возрождает (150/60 сек).
4. Цель — FFA-зачистка: киллфид, leaderstats (Kills/Deaths).

## Стрельба: FastCast / Server-Validated Ballistics

- Клиент **мгновенно** рисует трассер (шар + Trail), искры и звук — отзывчивость.
- Клиент шлёт серверу: `weaponId, origin, aimDir, seed, timestamp, scoped`.
- Сервер проверяет: флуд-фильтр, темп огня (RPM ±15%), магазин, перезарядку,
  перегрев ствола, `|serverNow − timestamp| ≤ 1 c`, origin в 8 studs от головы,
  единичность вектора. **Разброс детерминирован по seed** — сервер восстанавливает
  ровно то направление, которое видел клиент (модуль `WeaponConfig.ApplySpread`).
- Сервер прогоняет **свою** баллистику (`Ballistics.luau`): пуля летит с
  гравитацией (`GravityFactor`), снайперка имеет реальное время пролёта.
- Попадание: пехота → `DamageService` (хедшоты ×1.4–1.6), техника →
  `ArmorService.ApplyHit`, мины/дроны — спец-обработка. Остальным клиентам
  рассылается `FX_Shot` — они видят чужой трассер.

## Броня танка (многокомпонентная модель)

| Узел | HP | Эффект при 0 |
|---|---|---|
| Корпус (Hull) | 2000 | Уничтожение |
| Гусеница Л/П | 350 | Полная иммобилизация (не едет и не разворачивается) |
| Двигатель (корма) | 450 | Потеря хода + пожар 25 HP/сек корпусу |
| Погон башни | 600 | <50%: поворот башни −60%; 0: заклинивание |
| Боеукладка | 300 | HEAT/AP: 35% шанс мгновенного подрыва (cook-off) |

Зоны хитбоксов размечены тегами `CollectionService`: `Armor_Front` (0.5x),
`Armor_Side` (1.0x), `Armor_Rear` (1.5x), `Hitbox_Engine` (2.0x),
`Hitbox_AmmoRack` (2.5x), `Hitbox_Track_L/R`, `Armor_Turret`.

**Типы урона:** Kinetic (учитывает угол встречи, рикошеты), HEAT (игнорирует
угол, бьёт узлы), HE (сплеш, бонус ×1.5 по гусеницам, убивает лёгкую технику).

Автомат по танку не бьёт (множитель 0), ПКМ — символические 0.05x, РПГ/пушка
танка/C4 — полноценно. Лёгкая техника (мотоцикл, 150 HP) гибнет от всего.

## Спец-механики

- **C4**: сервер валидирует рейкаст (≤ 5.5 studs), заряд приваривается
  `WeldConstraint` к конкретной детали; детонация — 800 HEAT, на движок/БК —
  мгновенный вывод модуля / подрыв машины. Лимит 4 заряда на игрока.
- **ПТ-мины**: взвод 2.5 с; Spatial Query каждые 0.12 с; наезд = 650 HE +
  гарантированный срыв гусениц. Пули по мине тоже подрывают её.
- **FPV-дрон**: оператор замирает (уязвим), батарея 60 с, радиус видеоканала
  340 studs (дальше — помехи/потеря связи), Acro-крены по скорости; таран на
  ≥24 studs/s = 750 HEAT в конкретный хитбокс. Дрон можно сбить пулей.
- **Подавление ПКМ**: трасса рядом с камерой даёт экранную вспышку.

## Структура

```
src/shared   — конфиги (баланс), Remotes, Ballistics, HitboxTags, Signal
src/server   — MapBuilder (окопы/руины/площадки), VehicleFactory,
               ArmorService, VehicleControl, WeaponService (валидация),
               ExplosivesService (C4/мины/взрывы), DroneService,
               PickupService (контейнеры), LoadoutService, DamageService
src/client   — WeaponController (трассеры/прицел/разброс), DroneController,
               VehicleController, FXController, HUD (весь кодом)
```

Баланс правится в `src/shared/Config/` (WeaponConfig, VehicleConfig,
GameConfig) — никакой магии в коде.
